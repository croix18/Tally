Tally

IXL → FOCUS

Drop your IXL Score Grid here.

Per-period exports make a class each. A course-wide export (all your students in one file) is kept as the course's pool, and each Focus gradebook you drop makes a period's class from it.

How it works
One point per skill, one grade per unit. A skill is at goal when its SmartScore reaches the class goal (60 on-level, 67 accelerated, set from the file name; change it any time). Tap a skill in a unit to skip it for every class of that course. Paste each class's roster from FOCUS once and every Copy comes out in FOCUS order, with blanks where a student is missing from IXL.
Student data never leaves this device. It stays in this browser until you clear it, so on a shared computer hide names (the eye button) while projecting and clear it when you're done.
