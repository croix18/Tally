IXL → FOCUS

Drop your IXL Score Grid here.

One file per class period, or all of them at once. Focus gradebook exports can come along too.

How it works
One point per skill, one grade per unit. A skill is at goal when its SmartScore reaches the class goal (60 on-level, 67 accelerated, set from the file name; change it any time). Tap a skill in a unit to skip it. Paste each class's roster from FOCUS once and every Copy comes out in FOCUS order, with blanks where a student is missing from IXL.
Student data never leaves this device. It stays in this browser until you clear it, so on a shared computer use Names off while projecting and clear it when you're done.
