What it does now:
1. TEACHER GRID (private). Import IXL Score Grid exports (.xlsx/.csv) per period → students × units, one point per skill with SmartScore ≥ the period's threshold (default 67 accelerated / 60 on-level, editable). Unit detail shows raw scores; tap a skill to exclude it from the grade; hide/show units. Paste the FOCUS roster (ID columns tolerated) → Copy puts a unit's points column on the clipboard in FOCUS order; blank rows for roster students missing from IXL; no roster → copy always includes names. Name matching runs in passes (exact → loose); tap a flag to pick the right IXL account, ignore a withdrawn student, alias syntax `Last, First = IXL Name`. Hide names toggle (initials everywhere). Older-export confirm, all-zero-column confirm, placeholder exports block Copy. localStorage persistence; backup JSON (rosters/settings/history, no scores).
2. RACE (student-facing, hold-to-exit lock 1.5s, teacher UI hidden). Two leagues (per prep). Ranked by skills mastered per student; chips: % of assigned work, +N per student since last import, % of class moved up; "hardest workers" callout; team names; Both/Accelerated/On-level focus. Aggregate snapshots are kept per import for week-over-week. "Save as page" exports a static HTML with class totals only.
3. DATA LAB (student-facing, same lock). Pick a prep and a data set: any IXL unit (points), all skills mastered, any single IXL skill (SmartScore), any gradebook assignment/exam. One row per class: box plot (whiskers min–max by default, Tukey 1.5×IQR toggle), outliers as hollow circles, mean diamond vs median line, dot plot underneath on the same axis; "Reveal stats" toggle shows min/Q1/median/Q3/max/range/IQR/mean/MAD/outliers/shape. Quartiles use the middle-school method (median excluded from halves). No names anywhere.
4. GRADEBOOK IMPORT. Any non-IXL file is sniffed (xlsx zip / CSV / HTML-table-as-.xls / tab-text-as-.xls / real binary .xls → rejected with a message) and parsed as a generic grid: header row with a student-name column, other text columns = assignments; "Points Possible" row → max; category from a row above the header or guessed from the name; blanks = missing. A picker asks which period it belongs to. Feeds Data Lab only (no per-student view yet). Built WITHOUT having seen a real Focus export — the teacher has been asked for one.

Known open items: no real IXL export with names and no real Focus export have been tested; Google Fonts link kept (non-blocking) to match Deckhand; the race is IXL-only (assignment completion rate not yet scored).
