Scrubanonymize exports before sharing them for testing

What it does. Drop an IXL Score Grid export (.xlsx or .csv) or a FOCUS gradebook export (.xls, .csv, .html) and it replaces every student name and ID with a made-up one, keeping the file otherwise byte-for-byte the same shape: same columns, same rows, same scores, and the same form of each name (word count, commas, hyphens, apostrophes, middle names, Jr.). The same real student gets the same fake name in every file you scrub in this session, so an IXL file and a FOCUS file still line up.

Nothing leaves this page. There is no network code in this file. The real-to-fake key can be downloaded for your own reference; don't send it.
